# MajsterAssistance 🛠️

> **Aplikacja webowa wspomagająca planowanie i wycenę prac remontowo-budowlanych oparta o modele LLM.**  
> *Projekt pracy inżynierskiej*

---

## 📌 O Projekcie

System wspomagający niezależnych wykonawców (majstrów) oraz amatorów budowlanych w szybkiej estymacji i kosztorysowaniu robót. Aplikacja łączy niedeterministyczną wiedzę generatywnej sztucznej inteligencji (LLM) z deterministycznymi danymi o stawkach i kosztach robocizny przechowywanymi w relacyjnej bazie danych.

### Kluczowe Funkcjonalności

* **Strefa Publiczna (dla Amatorów):**
  * Interaktywny Asystent Techniczny (Czat AI).
  * Automatycznie generowana checklista prac oraz estymacja czasu realizacji.
* **Strefa Autoryzowana (dla Profesjonalistów):**
  * System rejestracji i logowania użytkowników.
  * Personalizacja stawek robocizny (stawka godzinowa, narzuty na materiały).
  * Kreator wycen i kosztorysów na bazie formularzy.
  * Zapis, edycja i persystencja kosztorysów.

---

## 🛠️ Stack Technologiczny

* **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Baza Danych:** SQLite
* **Integracja AI:** OpenAI API / Gemini API (JSON Mode, Bring Your Own Key)
